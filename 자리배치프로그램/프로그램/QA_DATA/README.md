# QA 테스트 데이터

이 폴더는 자리배치 프로그램의 QA 테스트를 위한 CSV 데이터를 포함하고 있습니다.

## 📋 시나리오별 테스트 데이터 (80명)

- **구성**: 영어 40명 (한국인 20, 외국인 20), 일본어 40명 (한국인 20, 외국인 20)

- **테스트 목적**: 국적 불균형 반대 상황 테스트

## 🎲 랜덤 테스트 데이터 (80명)

### **random_01.csv ~ random_10.csv**
- **설명**: 무작위로 섞인 참가자 데이터
- **구성**: 각 파일마다 다른 순서로 배치된 80명
- **테스트 목적**: 
  - 입력 순서에 관계없이 알고리즘이 동일하게 작동하는지 확인
  - 다양한 패턴에서의 중복 최소화 알고리즘 검증
  - 반복 테스트를 통한 안정성 확인

## 🧪 테스트 방법

1. **기본 배치 테스트**
   ```
   1. CSV 파일 업로드
   2. 테이블 설정 확인
   3. 1라운드 배치 → 2라운드 배치 → 3라운드 배치
   4. 각 라운드별 중복 확인
   ```

2. **늦참자 추가 테스트**
   ```
   1. 1라운드 배치 완료
   2. 늦참자 2-3명 추가
   3. 2라운드 배치 실행
   4. 늦참자가 올바르게 배치되었는지 확인
   ```

3. **이미지 내보내기 테스트**
   ```
   1. 각 라운드 배치 후 이미지 내보내기
   2. 이미지에 경고 메시지가 없는지 확인
   3. 모든 정보가 정확히 표시되는지 확인
   ```

4. **드래그 앤 드롭 테스트**
   ```
   1. 참가자를 다른 테이블로 이동
   2. 미배정 목록으로 이동
   3. 변경사항이 올바르게 반영되는지 확인
   ```
