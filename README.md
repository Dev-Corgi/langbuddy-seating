# 자리배치 프로그램

언어교환 자리배치 자동화 도구 - 독립 실행형 버전

## 기능

- ✅ CSV 파일로 참가자 데이터 입력
- ✅ 3라운드 자동 배치 알고리즘
- ✅ 드래그 앤 드롭으로 수동 조정
- ✅ 언어별 테이블 수 설정
- ✅ 한국인/외국인, 남/여 균형 체크
- ✅ 결과 복사 및 CSV 내보내기
- ✅ 로컬 저장소 지원

## 설치 및 실행

### 1. 패키지 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```

브라우저에서 http://localhost:3000 접속

### 3. 프로덕션 빌드
```bash
npm run build
npm start
```

### 4. 정적 사이트로 내보내기
```bash
npm run build
```

`out` 폴더에 정적 파일이 생성됩니다.

## CSV 파일 형식

### 필수 컬럼
- **이름** (또는 name): 참가자 이름
- **성별** (또는 gender): 남/여
- **국적** (또는 nationality): 한국인/외국인
- **언어** (또는 language): 영어, 일본어, 중국어 등

### 예시
```csv
이름,성별,국적,언어
김철수,남,한국인,영어
John Smith,남,외국인,영어
이영희,여,한국인,일본어
Yuki Tanaka,여,외국인,일본어
```

## 사용 방법

1. **CSV 업로드**: 참가자 정보가 담긴 CSV 파일을 업로드합니다.
2. **테이블 설정**: 언어별 테이블 수를 조정합니다 (자동 계산됨).
3. **자동 배치**: '자동 배치 실행' 버튼을 클릭하여 3라운드 배치를 생성합니다.
4. **수동 조정**: 드래그 앤 드롭으로 참가자를 이동시킵니다.
5. **결과 내보내기**: 복사 또는 CSV로 다운로드합니다.

## 배치 알고리즘

- 언어별로 그룹화하여 독립적으로 배치
- 한국인과 외국인을 균등하게 분배
- 3라운드 동안 같은 사람과 최소한으로 만나도록 최적화
- 50회 시도 후 최적 결과 선택

## 기술 스택

- **Framework**: Next.js 14 (App Router)
- **Styling**: TailwindCSS + shadcn/ui
- **Drag & Drop**: @dnd-kit
- **State**: React useState (로컬 상태)
- **Storage**: LocalStorage
- **CSV**: papaparse
