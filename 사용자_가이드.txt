========================================
자리배치 프로그램 사용 가이드
========================================

📌 이 프로그램을 사용하는 방법 (개발 지식 불필요!)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
방법 1: Netlify로 무료 호스팅 (추천) ⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. https://app.netlify.com/drop 접속

2. 받으신 ZIP 파일의 압축을 풉니다

3. 압축 푼 폴더 안의 모든 파일을 
   Netlify 페이지의 점선 박스로 드래그 앤 드롭

4. 즉시 웹사이트 주소가 생성됩니다!
   예: https://your-site-name.netlify.app

5. 이 주소를 북마크하거나 공유하세요

✅ 장점:
- 완전 무료
- 클릭 몇 번으로 완료
- 인터넷만 있으면 어디서나 접속 가능
- 모바일에서도 사용 가능


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
방법 2: GitHub Pages로 호스팅
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. GitHub 계정 생성 (무료)
   https://github.com

2. 새 저장소 만들기
   - 이름: seating (아무거나 가능)
   - Public 선택

3. 압축 푼 파일들을 모두 업로드

4. Settings → Pages 메뉴
   - Source: Deploy from a branch
   - Branch: main 선택
   - Save 클릭

5. 몇 분 후 웹사이트 주소 생성
   예: https://yourusername.github.io/seating


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
방법 3: 로컬 실행 (인터넷 필요)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

압축 푼 폴더에서:

1. 주소창에 입력: cmd
2. 엔터 (명령 프롬프트 열림)
3. 다음 명령어 입력:

   npx serve

4. 브라우저에서 http://localhost:3000 접속

⚠️ 주의: 이 방법은 컴퓨터를 끌 때마다 다시 실행해야 합니다


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
💡 추천: 방법 1 (Netlify Drop)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

가장 쉽고 빠르며, 한 번 업로드하면 영구적으로 사용 가능합니다.
개발 지식이 전혀 필요 없습니다!


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 프로그램 사용법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. CSV 파일 업로드 또는 직접 입력
   - 형식: 이름, 성별, 국적, 언어

2. 테이블 설정 (자동 계산됨)

3. 1라운드 배치 → 2라운드 배치 → 3라운드 배치

4. 이미지로 내보내기 (각 라운드별)

5. 늦참자 추가 기능 사용 가능


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
❓ 문제 해결
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 스타일이 안 보여요
A: 파일을 직접 더블클릭하지 마세요. 
   위의 방법 1, 2, 3 중 하나를 사용하세요.

Q: 데이터가 사라졌어요
A: 브라우저의 로컬 저장소에 자동 저장됩니다.
   같은 브라우저, 같은 주소에서 접속하세요.

Q: 모바일에서도 되나요?
A: 네! 방법 1, 2로 호스팅하면 모바일에서도 사용 가능합니다.
