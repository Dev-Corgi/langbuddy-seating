========================================
자리배치 프로그램 배포 가이드
========================================

📌 완전한 단일 HTML 파일은 기술적으로 불가능합니다
   (React/Next.js는 여러 파일로 분리되어 작동)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ 가장 쉬운 방법: Netlify Drop (추천)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 빌드 실행:
   npm run build

2. https://app.netlify.com/drop 접속

3. out 폴더 전체를 드래그 앤 드롭

4. 완료! URL 생성됨 (예: https://seating-app.netlify.app)

장점:
✅ 완전 무료, 영구 사용
✅ 모든 스타일과 기능 완벽 작동
✅ 모바일에서도 작동
✅ URL 하나로 공유 가능
✅ 개발 지식 불필요


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
방법 2: 로컬 실행 (인터넷 필요)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 빌드 후 out 폴더를 사용자에게 전달

2. 사용자가 out 폴더에서 명령 프롬프트 실행:
   - 주소창에 "cmd" 입력 후 엔터
   
3. 다음 명령어 실행:
   npx serve

4. 브라우저에서 http://localhost:3000 접속

주의: 컴퓨터를 끌 때마다 다시 실행 필요


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
방법 3: GitHub Pages
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. GitHub 계정 생성 (무료)

2. 새 저장소 만들기 (Public)

3. out 폴더 내용 업로드

4. Settings → Pages
   - Source: Deploy from a branch
   - Branch: main
   - Save

5. 몇 분 후 URL 생성
   (예: https://username.github.io/seating)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
❓ 왜 단일 HTML 파일은 안 되나요?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

이 프로그램은 다음 기술을 사용합니다:
- React (JavaScript 프레임워크)
- Next.js (빌드 시스템)
- TailwindCSS (스타일링)
- shadcn/ui (컴포넌트)

이들은 모두 여러 파일로 분리되어:
- index.html (메인 페이지)
- _next/static/*.js (JavaScript 코드)
- _next/static/*.css (스타일)
- public/* (이미지, CSV 등)

단일 HTML로 만들려면:
1. 모든 JavaScript를 인라인으로 삽입
2. 모든 CSS를 인라인으로 삽입
3. 모든 이미지를 Base64로 변환
→ 파일 크기 10MB+ (비현실적)
→ 유지보수 불가능

💡 결론: Netlify Drop 사용을 강력 추천
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- 가장 쉽고 빠름 (5분)
- 완전 무료
- 모든 기능 완벽 작동
- URL 하나로 모든 사용자가 접속 가능
- 업데이트도 간단 (다시 드래그 앤 드롭)
